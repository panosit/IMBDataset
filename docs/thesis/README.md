# Formal thesis draft

`thesis_manuscript.md` is an auditable manuscript **draft and evidence ledger**. `build_pdf.py` creates the committed `thesis_detailed.pdf` (at least 100 pages) without external document software. The page count is supplied by structured appendices for experiment records, annotation sheets, result tables, and reproducibility logs; it must not be represented as a completed 100-page research thesis until its placeholders are filled by executed experiments and verified literature review.

Build with:
```bash
python docs/thesis/build_pdf.py
```
