# Dissertation PDF build

`thesis_detailed.pdf` remains at the repository root for external delivery. It is
built from `build_pdf.py` as a polished **doctoral dissertation draft** with
front matter, substantive chapter structure, result-insertion sections, and
appendices for literature, experiments, figures, annotation, validation, and
reproducibility.

The document is intentionally evidence-first: it carries a draft footer and
explicit placeholders until literature citations and experiment artifacts have
been verified. It must not be represented as a completed empirical PhD thesis
until those requirements are met.

Build it with:

```bash
python docs/thesis/build_pdf.py
```
